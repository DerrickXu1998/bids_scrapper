# Installation

## Stable release

To install bids_scrapper, run this command in your terminal:

```sh
uv add bids-scrapper
```

Or if you prefer to use `pip`:

```sh
pip install bids-scrapper
```

## From source

The source files for bids_scrapper can be downloaded from the [Github repo](https://github.com/DerrickXu1998/bids_scrapper).

You can either clone the public repository:

```sh
git clone git://github.com/DerrickXu1998/bids_scrapper
```

Or download the [tarball](https://github.com/DerrickXu1998/bids_scrapper/tarball/master):

```sh
curl -OJL https://github.com/DerrickXu1998/bids_scrapper/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd bids_scrapper
uv pip install .
```
